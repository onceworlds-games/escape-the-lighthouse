# Escape the Lighthouse

Locked in a lighthouse on a stormy night. Search, solve, escape.

A 3D point-and-click escape room in three chapters (the keeper's cottage, the radio room, the lamp room) with searching,
close-ups, an inventory you can inspect and combine, a journal of clues, hints, timers, stars and auto-saves. Rooms are data
files in `src/data`; one engine plays any of them.

Play: https://onceworlds.com/play/escape-the-lighthouse

Tests: `npm test` (the puzzle engine is pure and every room is played through by script). Build: `npm run build`.

See `DESIGN.md` for the puzzle graphs and how to add a room.
